공간담다 사용 안내

  1. 공간 설정에서 이름과 실제 가로·세로를 입력하고 적용하세요.
  2. 가구·용품·구조·구역에서 필요한 물품을 추가하세요.
  3. 드래그로 이동하고, 더블클릭으로 이름을 바꾸세요.
  4. Ctrl+클릭 또는 여러 개 선택 모드로 묶어 이동하세요.
  5. 벽·구역은 위치·편집 잠금으로 고정할 수 있어요.
  6. 거리 측정을 켜고 도면의 두 지점을 클릭하세요.
  7. 층을 추가하고, 3D 둘러보기에서 배치를 확인하세요.

선택 테두리: 초록=단일 선택 · 파랑=다중 선택 · 황금색=잠금
모서리를 드래그해 크기 조절 · 위쪽 원형 핸들로 회전 (Shift: 15도 단위)
Delete로 선택 삭제 · Ctrl+Z로 복구

여러 개 선택 후 정렬·간격 맞추기를 사용할 수 있습니다. 잠긴 물품은 정렬에서 제외됩니다.
Ctrl+C 복사 · Ctrl+V 붙여넣기 · Ctrl+D 복제
다중 복사는 묶음 수와 이동 간격을 지정합니다. 이름은 기본적으로 복사하지 않습니다.

Ctrl+Z 취소 · Ctrl+Y / Ctrl+Shift+Z 다시 실행
+ / − 확대·축소 · 0 전체 보기

자동 저장은 이 브라우저에만 보관됩니다. 다른 PC에서는 저장 버튼으로 받은 JSON 파일을 불러오세요.

3D 가구 높이는 기본값이며, 외벽은 배경으로 표시됩니다. 정확한 건축 도면 검토용은 아닙니다.
